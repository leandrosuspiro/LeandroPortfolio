Problem

Stock levels lived in individual spreadsheets, causing miscommunication, stockouts, and time lost to manual checking as the team grew.

Solution

A browser-based inventory app with role-based access, persistent database, full activity logging, and one-click Excel export — no installation needed.

Key decision

Chose a web app over a shared spreadsheet to enforce data integrity and support concurrent users. Prioritised audit trail after research surfaced accountability as a top concern.

Scope

Multi-user auth, material category grouping, crop/sheet tracking, review alerts, substitute material flagging, Excel export, activity log.

Sheet Nesting & Cut List Generator
Two linked tools for project managers · HTML / JavaScript

Problem

Project managers had no reliable tool to calculate material requirements and cutting layouts. Without it, quotes were hard to price accurately and excess material was routinely ordered, driving up costs.

Solution

A Cut List Generator that structures part requirements from a template, paired with a Sheet Nesting Tool that visually optimises how parts are laid out on each sheet — giving PMs clear, accurate data for quoting and purchasing decisions.

User & adoption

Built exclusively for project managers. No training needed — the step-by-step flow makes it immediately usable, and the product continues to evolve as PMs share feedback and new needs emerge.

Output

Exports to PDF and Excel, in formats already familiar to the team. Keeps the PM in their existing workflow while eliminating the manual guesswork.

✓ More accurate material quotes
✓ Reduced material waste
✓ No training required
✓ Continuously evolving with user feedback

Project Tracker — Gantt Generator
Production planning tool · HTML / JavaScript / Excel

Problem

The company had no Gantt chart tool and no budget to acquire one. Senior project managers — many of whom had never used scheduling software — had no structured way to communicate production timelines, making it difficult for the team to plan and prioritise work.

Solution

A lightweight Gantt generator built around the formats and workflows the team already knew. Project managers fill in a familiar spreadsheet template and the tool produces a clear, visual timeline instantly — no software to learn, no licence to buy.

Key decision

Rather than introducing complex project management software that senior PMs would resist, I designed something simple enough to be picked up immediately — meeting the users where they were, not where I wanted them to be.

Scope

Task and dependency mapping, employee hour allocation, delivery date tracking, visual Gantt output. Runs in the browser with no installation or IT involvement.

✓ Adopted by senior PMs with no prior tool experience
✓ Clear production timelines from a familiar spreadsheet
✓ Zero cost, zero install

Supplier Directory
Internal knowledge tool · HTML / JavaScript / JSON

Problem

Each project manager worked with their own set of vendors, with no visibility into what others were doing. Supplier knowledge — quality track record, how they handle costs, how they deal with issues — existed only in individual heads or scattered inboxes. This fragmented approach made it hard to build consistent vendor relationships and put unnecessary pressure on our purchaser to field the same questions repeatedly.

Solution

A centralised supplier directory where the whole team can search vendors, read notes on how each supplier handles jobs in terms of quality and cost, and find the right contact quickly. Admin-controlled to keep data clean and consistent.

Key decision

The goal wasn't just to store contacts — it was to build institutional knowledge around vendor relationships. Adding structured notes on quality and cost behaviour meant the directory became a decision-support tool, not just an address book. This also reduced the load on our purchaser, who no longer needed to be the sole keeper of that knowledge.

Scope

Full-text search, tag-based filtering by category, supplier profiles with notes on quality and cost, admin access control, add/edit/delete suppliers. Single-file — no server or IT required.

✓ Consolidated fragmented vendor knowledge
✓ Stronger, more consistent supplier relationships
✓ Reduced load on the purchaser
✓ PMs can make informed vendor choices independently
